## 1. 视觉与质感规范（先读这一节）

### 1.1 基调

**仪表盘，不是图表海报。** 这一轮的主角是甘特，它承载 300 条任务 × 12 周的密度，所以：白底、1px 线、**零渐变、零装饰阴影**（阴影只给浮层：tooltip `--sh-3`、下拉 `--sh-2`）；颜色**只做编码，不做氛围**——红色是配额资源，仅出现在逾期条、风险数字、破坏性按钮。区分「层级」靠 1px 线、字重和 44/32/40 的三级行高，不靠底色块堆叠。

三条不可让步的质感线：
1. **数据对齐优先于美观**：所有数字 `font-variant-numeric: tabular-nums`；左列文字右边界齐、时间轴刻度左边界齐；翻屏时列宽不重算（同一档位内 `--day-w` 恒定）。
2. **条 = 时间，不是卡片**：任务条上不写标题、不带图标、不做渐变，18px 高、3px 圆角，读的是「位置和长度」。
3. **每个状态都有非颜色通道**：CANCELLED 用**虚线中轴线**（形状）、逾期用 **1.5px 红描边 + 红 Pill 文字**、推算起点用**虚线左帽**、越界用**箭头 + tooltip 文字**——色弱与灰度打印下全部可读。

**禁用态**：`opacity` 不用（既有口径）；禁用 = 边框 `--c-line`、文字 `--c-ink-400`、`cursor:not-allowed`、`aria-disabled="true"`。甘特里「显示已完成」关闭后已完成条**直接不渲染**（不是灰化），避免"看得见但点不动"。

### 1.4 动效与三态

- **折叠/展开**：不做高度动画（300 行会掉帧）；只做 chevron 旋转 180ms + 子行 `opacity 0→1` 120ms（`transform` 不动，避免整页重排抖动）。
- **切档 / 翻屏**：不横滑、不缩放动画；内容区先切骨架（同一模板，8 行灰条），数据到达后一次绘出。**禁止**旧的条淡出新条淡入（会读成"数据在动"）。
- **骨架**：行高与真实行一致（44/32/40），灰块 `--c-line-soft`，`@keyframes pulse { 0%,100%{opacity:.55} 50%{opacity:.9} }` 1.2s 无限；表头与左列结构保留，不整块灰掉。
- **空态**（窗口内 0 条）：不画空网格。48 图标 + 「这个时间范围内没有任务」+ 两个动作「扩大范围（本季）」（切月档 6 个月并回到今天）/「回到今天」。
- **错误态**：复用 `ErrorState` 替换画布区，PageHeader 与摘要条保留，不整页白屏。
- **加载失败重试**：`ErrorState` 的 retry 直接重发当前请求（不重置筛选/窗口）。

### 1.6 几何自洽（按最大值算，不许本节与其它节打架）

- **左列 280 任务行**：`padding-left 12` + `StatusBadge sm` 56 + `gap 8` + 标题弹性 + `padding-right 8` → 标题可用 **196px**，13px 中文 ≈ 14 字，超出省略并 `title` 补全。行高 **40** = 20（标题）+ 16（负责人）+ 4，不溢出。
- **时间轴表头 48** = 月带 24 + 刻度 24；刻度文字 11/16 单行，不加第二行说明。
- **`--day-w` 计算**：`dayW = clamp(40, floor(timelineW / daysPerScreen), 96)`；`timelineW = 容器宽 − 280`。1440 视口下 `timelineW≈1063 → dayW=75（日档）/12.6（周档）`；1280 视口下 `dayW=48.6（日档）`；到 40 下限时**不横向滚动**，改为刻度抽稀：日档每 2 天一个日号，周档每 2 周一格。**任意档位下 bar 宽度复算 `width = max(10, (due−start+1天)×dayW)`，10px 下限保证 1 天任务在月档（dayW≈5.6）仍可见。**
- **任务条 18 高**：行 40 → 垂直偏移 `(40−18)/2 = 11`，上下各留 11，不压行线。
- **摘要 chip 行**：5 个 chip（逾期/风险/进行中/待验收/已完成）+ 1 个开关 + 1 条提示，`flex-wrap`，gap 8。1344 宽时一行（5×112 + 4×8 + 200 + 主色提示 ≈ 810）；960 宽时折 2 行（第二行不改变上方间距 `--sp-3`）。
- **会议进度 4 小卡**：`min-width 132`，`4×132 + 3×12 = 564`，容器内宽 ≥564 不折行；<640 时 `2×2`。
- **五步闭环条**：桌面每个节点 = 18 圆 + 8 间距 + 4 字标签 52 = 78；4 条连接线 `flex:1; min-width:24` → 最小 `5×78 + 4×24 = 486`，落在面板内宽（≥640 屏）内。**≤640px 切换为 5 等分竖排**（圆 16 + 间距 4 + 11px 标签），单格 ≥ 343/5 = 68 ≥ 44（4 字标签宽），高度 44。
- **主题配置表**：列宽 `200 / 132 / 96 / 96 / 80 / 152 = 756 ≤ 968`（设置页卡片内宽），无横滚。
- **建会弹窗（lg 640）**：内容内宽 592；决议子卡片第二行 = 负责人 220 + 截止 176 + gap 12 = 408 ≤ 592；描述占整行。

### 1.7 本产品的反面清单（本轮，出现即返工）

1. 任务条上写标题 / 两行文字 / 放图标（行高 18 放不下，且与左列重复）。
2. 用主题色填充任务条（与状态色打架，违反 PRD §10 决策五）。
3. 逾期条被窗口裁掉，要横向滚动才看得见（直接违反 AC-11 与反面目标 2）。
4. 甘特里出现空网格当空态。
5. 切档/翻屏时旧数据先留着再替换（读起来像数据在跳）。
6. 折叠行做整页高度动画（300 行会卡）。
7. 摘要 chip 只有数字没有词（「3」不知道是逾期还是待验收）。
8. 会议详情同时存在「已转 2」与「任务进度 2/3」两套计数（AC-4 明令禁止）。
9. 五步条把「提交」「验收」合成一步（AC-6 明确要求 5 步）。
10. `ThemeTag` 页面自拼颜色或自行比较 `enabled`（AC-9 单点约束）。
11. 数字用比例字体、翻屏时跳动。
12. 人员选择器退回复选框长列表（本轮修的就是这个）。

### 2.2 甘特的数据与计数口径（交 TECHNICAL 的契约要点）

| 项 | 口径 |
| --- | --- |
| 窗口 | 周档默认 = 「今天所在周的周一往前 2 周」的周一 00:00 起 12 周；日档 14 天；月档 6 个月。`←/→` 按整屏平移；「回到今天」= 当前档位默认窗口 |
| 状态 / 逾期 | 只用接口返回的 `status / isOverdue / overdueDays / isAtRisk`，前端**零日期比较**（AC-7 grep 断言） |
| `逾期 N` | **全局**：全部「未完成且 `due_date` < 今天」，与看板同值；这些任务**无视窗口返回并 pin 在左边界** |
| `风险 N` | **全局**：逾期未完成 ∪ 待验收且 `submittedAt` ≤ 今天−3 天，与看板同值；接口对「逾期 ∪ 风险」任务无视窗口返回 |
| `进行中 / 待验收 / 已完成` | 当前窗口内计数，chip 带「本窗口」提示 |
| 风险条越界 | 右界外的风险条在**右边界**渲染 6px 红色三角夹标 + tooltip「风险 · 截止 MM-DD（窗口外）」，不静默丢弃 |
| 截断 | 排序：逾期 → 风险 → 进行中 → 待验收 → 待开始 → 已完成，同类按 `due_date` 升序；>300 返回 `truncated=true` + 窗口内总数 |

> 这样处理的原因：AC-7 要求「甘特与看板的风险数字必须相等」，只能是全局口径；AC-11 要求「点数字能定位」，则被计入的任务必须在图上可达。两者同时成立的做法就是「全局计数 + 逾期左 pin + 风险右夹标 + 点数字自动翻到首个匹配条」。**这条口径必须在 TECHNICAL 里落成接口参数，不允许前端自行补齐。**

- 折叠：主题行与项目行都可折叠；**会话内保持**（模块级 `useGanttView`，切档/翻屏/筛选/进出详情页不重置，刷新页面重置）。首屏全展开；主题数 >12 时，默认折叠「既无风险又无逾期」的主题。

**空态 / 加载 / 错误**
- 窗口内 0 条：不画网格；`EmptyState` + 「扩大范围（本季）」「回到今天」。
- 首次加载：骨架（表头 + 左列结构 + 8 行灰条）；切档/翻屏：整块骨架，不保留旧条。
- 失败：`ErrorState` 替换画布区（`PageHeader` 与摘要条保留），retry 重发当前请求。
- 请求次数：切档/翻屏/筛选各 1 次（`seq` 序号丢弃过期响应，沿用任务池做法）。

### 4.1 `GanttChart` `[新增]`

- 图层：`grid`（竖线/周末底/今天线）用绝对定位 div；条用绝对定位 div（不画 SVG——矩形 + 圆角 CSS 足够，且省一层坐标换算）；避免为 300 条各建一个 SVG。

### 4.2 `GanttBar` `[新增]`

Props：`task`、`x`、`width`、`pinnedStart/pinnedEnd`、`estimatedStart`；渲染为 `<button class="bar">`，`aria-label` 拼接「标题，MM-DD 至 MM-DD，状态，逾期 N 天」。视觉全由 class 决定（status 决定色，`pinned` 决定虚线帽，`estimatedStart` 决定虚线帽 + ≈）。

### 4.3 `ThemeTag` `[新增]`

Props：`name`、`color`、`softColor`、`borderColor`、`enabled`。空名不渲染（绝不产生空标签）；`max-width:128` 省略 + `title` 补全；几何与 `ProjectTag` 逐像素一致。

### 4.4 `ThemeConfigTable` / `ThemeFormModal` `[新增]`

结构、行内排序与 409 处理沿用 `ProjectConfigTable` / `ProjectFormModal`；只把「项目」换成「主题」、把上限 200 换成 100、把颜色选择换成 8 色板。

### 4.5 `UserMultiSelect` `[新增]`

- 容器：`min-height:36`、1px `--c-line`、`--r-md`、`padding:4 6`、`flex-wrap`、gap 4；聚焦时 `--focus-ring` + 边框 `--c-primary-border`。
- chip：高 24、`--r-sm`、`--c-primary-soft` 底、`--c-primary-border` 边、`--c-primary` 字、`max-width:120` 省略、× 20×20。
- 输入框：`flex:1; min-width:96; height:24; 13px;` 无边框。
- 下拉：`top:calc(100%+4)`、`width:100%`、`max-height:264`、`--r-lg`、`--sh-2`、`z-index:var(--z-dropdown)`；选项 32 高，选中右侧 ✓，hover `--c-surface-hover`；空态 32 高「没有匹配的用户」。
- 键盘：↑↓/Home/End/Enter/Esc/Backspace（空输入时删最后一个 chip）/Tab 关闭；`role="combobox" aria-expanded aria-multiselectable`。

### 4.6 `TaskStatusFlow` `[新增]`

Props：`status`、`ownerName?`、`dispatcherName?`。纯展示，无 API、无权限判断；`aria-label` 为「任务进度：已完成派发，当前进行中」这样的整句。

### 4.7 `MeetingTaskProgress` `[新增]`

Props：`items`（该会议任务）、`decisionTotal`、`loading`、`error`；在 setup 内一次 `computed` 出 5 个计数（`converted/unfinished/overdue/done/risky`），模板只引用常量，禁止模板内 `filter().length`。

### 4.8 `AppSearchSelect` 增量 `[修订]`

新增 `allowCustom?: boolean`：无匹配时列表底部出现一行「使用「<query>」作为主持人（非系统用户）」；选中把原文 emit 出去。当前值不在选项中时，关闭态显示原文 + 后缀「（非系统用户）」（`--c-ink-500`），打开态以原文作初始 query。既有项目场景不传该 prop，行为逐字节不变。

## 5. 权限的界面表现 `[修订]`

| 能力 | ADMIN | EXEC | OWNER |

## 6. 响应式与 H5 `[增量]`

- **甘特 <1024**：侧栏折叠到 64；左列 280→200（标题可用 116，仍单行省略）；表头仍 48；列宽用 `clamp(40,…)` 重算，日档自动抽稀为每 2 天一个刻度。
- **甘特 <768（H5）**：默认降到「日档 7 天/屏」，`←/→` 按 7 天平移；摘要 chip 两行；tab 栏变为横向可滚的分段控件；折叠两级保留（否则 300 行无法浏览）。
- **建会弹窗 <640**：`size="lg"` 退化为全屏（`max-width:92vw`，正文独立滚动）；决议子卡片第二行改为纵向两行（负责人、截止各占整行）。
- **会议进度区 / 五步条 / 主题表**：按 §1.6 的断点折行；表格 <760 时保留横滚，不隐藏列（数据不可丢）。
- 触控命中区不小于 32×32（折叠箭头、chip ×、行内编辑）；甘特条在触控下不依赖 hover——点击直接进详情，tooltip 改为长按 400ms 出现。

## 7. 无障碍要点 `[增量]`

- 甘特：外框 `role="tree" aria-label="进度甘特"`；主题/项目行为 `treeitem` + `aria-expanded`，任务行为 `treeitem`（`aria-level` 3）；任务条的 `aria-label` 必须含标题、起止、状态、逾期天数（不能只有颜色）。
- 折叠：chevron 是 `<button aria-expanded aria-controls>`，图标 `aria-hidden`，可访问名「展开/折叠 主题：Q4 交付冲刺」。
- 摘要 chip：`<button aria-pressed="true|false">`，文字含标签 + 数字（「逾期 3 条」），不用 `title` 替代文本。
- 键盘：Tab 顺序 = 页头控件 → 摘要 chip → 折叠箭头 → 行 → 条；提供跳过链接「跳过甘特明细」（`sr-only`，focus 可见）。
- 颜色：状态三重编码（色 + 文字/形状 + 图标）；逾期不只靠红色（Pill 有「逾期 N 天」文字）；主题色点旁必有主题名。
- 表格：`<th scope="col">`，行可点也保留可聚焦元素（`<button>` 或 `RouterLink`），不靠 `@click` 的 div。
- 动效：`@media (prefers-reduced-motion: reduce)` 关闭 chevron 旋转与 skeleton 脉冲（保留最终态）。
- 表单错误：`aria-invalid` + `aria-describedby` 指向错误文案，`role="alert"`；提交失败焦点移到首个错误字段。
